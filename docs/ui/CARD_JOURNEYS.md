工作台单列先显示班级通知和待办任务，双列中两张卡片位于主栏。「今日课程」卡片集中展示当前或下一节课和今天的安排。待办卡固定显示优先的两项，点卡片打开任务列表。通知有多条时每 5 秒向上轮换，系统关闭动画时显示静态摘要。点击条目可进入对应详情。

卡片内完成、重试、附件、编辑和选择按钮各自执行原操作。没有稳定 ID 的任务或通知行进入对应列表。课表没有后端课次 ID，使用日期、节次、完整教室和课程名在当前课表内核对，无法唯一匹配时停在当天安排。

## beta79 验收记录

在 Android 16 / API 36 模拟器上用虚构班级、课表、账号及电量采样验证。桌面行通过系统 AppWidgetHost 绑定实际 provider，再触发 RemoteViews 的 PendingIntent。

|入口或条件|模拟器观察|
|---|---|
|明天的下一节课|课表日视图选中明天，详情显示对应日期、节次、时间和完整教室；从工作台打开后一次返回原位置。|
|今日课程卡面|日视图选中今天，显示已结束课程的名称、时间和教室，返回工作台。|
|待办与作业卡面|待办列表选中“重要”后退出，再点卡面仍为原筛选；直接点普通任务行仍能打开详情。作业卡面进入班级作业列表。|
|工作台任务与班级作业行|分别显示个人任务详情和班级作业详情。个人任务可完成、撤销，班级作业显示截止时间、提醒和加入个人任务入口。|
|工作台通知行|标题、发布时间与内容开头位于同一详情面板，处理按钮位于内容之后。旋转屏幕后保留目标。|
|已关注宿舍|进入后显示同一宿舍、16.8 度、低电和采样时间，可以调整阈值。24 小时趋势读取 18 个虚构采样点。|
|四个桌面组件|课表行进入指定课程；任务首行进入个人任务、作业次行进入班级作业；通知行进入正文；工作台摘要进入工作台。|
|冷启动及登录|无会话时先登录，成功后打开待办目标；模拟器系统返回退出冷启动目标。|
|后台恢复及连续入口|已打开应用时再次投递通知，旋转后重复投递同一目标，再按一次返回工作台。缺失任务 ID 进入任务列表。测试账号请求隐藏通知 ID 时仍在可见列表，出现“当前可见的通知中找不到这条内容”，隐藏标题未显示。|
|通知缓存与失败|有本次进程缓存时，模拟接口返回 503，列表仍显示原通知和重试栏；恢复服务后点重试，提示消失。冷启动无缓存且断开调试网络时显示失败页和重试。|
|外观与尺寸|320 dp 宽、1.5 倍字号下，长中文任务标题完整换行，期限另起一行，详情仍有截止时间和底部操作。检查亮色、暗色、跟随系统，以及系统和应用深浅相反时的组件。系统组件宿主另用浅色、深色及高纹理底图检查边缘和文字。|

普通测试账号可见的工具中，抽签、分组、体测、任务、通知、投票、文件传输、课表、电费、地图、演示、水量、名单、点名、快递和诊断已逐个从工具磁贴打开，并返回原来的工具分页。未注入投票或点名数据时验证的是失败和重试首屏；演示验证的是空目录及上传入口。教务首次进入先打开账号设置，关闭后进入教务登录页，系统返回回到教务磁贴所在位置。没有向教务提交账号或密码。管理员独有的统计页仅核对权限和代码路径。

单元测试共 2,000 项，其中 1,998 项通过。两个依赖外部 staging 环境的冒烟用例按原条件跳过。Debug、Release 和发布版必要 lint 检查通过。青瓷亮暗色普通文字、主操作及对应实色底面的测试阈值为 4.5∶1。组件测试另覆盖不同尺寸、独立配色、未登录清除行数据、旧缓存兼容及各行独立点击请求。

截图保存在工作区 `releases/android/beta79-cards/`。四组 `*-pair.png` 分别对应课表、待办、通知和电费，`widgets.png` 为四种选择器预览。浅色、深色和纹理的组件实拍分别见 `widgets-light.png`、`widgets-dark.png` 和 `widgets-texture.png`。截图中的数据均为虚构样例。

在模拟器系统桌面的组件选择器中展开“枫丹工具箱”可见四种预览。安装发布签名包，添加待办组件后，未登录时点击进入身份核验，系统返回回到该组件。分别设置浅色、深色和高纹理系统壁纸，实拍见 `launcher-wallpapers.png`。其中有内容的四组件组合图来自 AppWidgetHost。不同厂商启动器的圆角裁切、自由缩放和后台调度仍需真机复核。

## 莫奈配色与桌面布局

Android 12 及以上默认读取系统壁纸生成的 Material 配色。主操作、选中态、文字、底面、工具图标和默认桌面组件共用相应颜色角色。在“我的 → 外观 → 莫奈壁纸配色”可切回青瓷；Android 8–11 使用青瓷。海蓝、琥珀、丁香仍按组件实例保存。

|组件|紧凑视图|滚动集合|独立操作|
|---|---|---|---|
|待办|首项、截止时间和个人未完成数量，班级作业注明来源|依原优先级显示待办与未导入的班级作业。宽高充足时按星标和期限分成四组，组内保留所有记录|点事项打开详情。空间允许时显示完成按钮及新建入口|
|课表|正在上课或下一节、时间和可用的教室|当前课或下一节在前，接着列出今天和明天的后续课次。宽高充足时显示日期分组|点课次定位课程，点日期定位当天安排|
|工作台|正在上的课优先。没有正在上的课时，按课程与待处理事项的紧迫程度展示一项|课程、待办、作业、通知依原顺序排列。宽版双列，窄版单列，高版把课程排在整行并分别显示时间和教室|点摘要打开对应记录，空卡进入该分类。「总览」打开工作台，空间允许时可新建待办、就地完成，或通过「课表／列表」打开分类|
|通知|重点通知及总条数|沿用通知主列表的置顶、状态和时间排序，宽版增加摘要|点记录打开对应通知，空间允许时显示手动刷新|

四个桌面组件使用同一套 RemoteViews 外壳。列表使用剩余高度，滑动内容按卡片圆角裁切，标题栏「全部」打开相应的完整页面。摘要模式保留数量或状态和「全部」入口。旧缓存仍可读，若缓存只有部分记录，列表标题栏提示剩余条数。缩放按启动器报告的可用 dp 和系统字号计算，工作台双列、横排字段和分组会随字体放大提高宽度门槛。配置允许横纵缩放，声明的最小尺寸为 132 × 60 dp，目标初始跨度为 3 × 2 格。启动器按自己的网格、系统边距和取整规则分配实际尺寸。

[Google Tasks 桌面组件](https://support.google.com/tasks/answer/10478781) · [Google Calendar 桌面组件](https://support.google.com/calendar/answer/10249848)

新版桌面工作台借鉴 Google Calendar 的近期日程、Google Tasks 的独立新建入口，以及 Google Keep 和 Apple 提醒事项的就地完成。摘要和列表按钮使用不同点击区域，改变卡片尺寸后仍会定位到同一条记录。只剩一个次级操作位时，个人待办优先保留完成按钮，可从总览进入完整待办。[Google Keep](https://support.google.com/keep/answer/13302793) · [Apple 小组件交互指南](https://developer.apple.com/design/human-interface-guidelines/widgets)

在 API 36 模拟器分别应用绿色、梅紫色壁纸，并切换深色。真实任务详情的底面、操作与默认组件同时变化。模拟器系统桌面的待办组件点击加号进入新建表单，点个人任务和班级作业分别进入各自的详情。截图使用虚构内容，位于工作区 `releases/android/monet-widgets/`。其中 `monet-comparison.png` 对照三种外观，`widgets-mint.png` 和 `widgets-dark.png` 展开四个组件。

## 网页配色与桌面操作

默认采用网页端的奶油底、雾青、灰蓝和暖沙，并映射到 Material 3 的表面、描边和操作色。未设置壁纸取色的设备在升级时使用网页配色，显式选择壁纸取色或单个组件颜色的设备继续使用该选择。

| 桌面点击区域 | 操作与返回位置 |
| --- | --- |
| 个人任务旁的勾选框 | 按任务 ID 完成本轮，留在桌面并更新数量。离线编辑保存在本机，联网后同步。已完成、已删除、已退出或其他账号的旧按钮不会改变新的任务。 |
| 任务标题、班级作业标题 | 进入对应详情。空间不足时优先保留标题，详情内仍有完成操作。 |
| 通知标题栏的刷新按钮 | 保留当前缓存，联网时刷新通知，留在桌面。点通知标题仍可阅读正文。 |

Android 16（API 36）模拟器在飞行模式下实测。系统桌面点「归还展板」的勾选框后仍停在桌面，数量从 3 变为 2，班级作业仍在原组件内。点个人任务标题打开详情，勾选每日重复任务后生成一个次日实例。通知刷新在断网时保留了缓存标题。亮暗界面、系统桌面前后截图和四个选择器预览位于工作区的 releases/android/web-m3-widgets 目录。
