## 2. 验证证据

### 2.1 构建
- `gradlew.bat assembleDebug` → `BUILD SUCCESSFUL`（配置缓存命中，日常增量 3–15s）。
- 版本矩阵经三个冒烟工程交叉验证：built-in Kotlin 下 Kotlin 版本由声明的 compose/serialization 插件版本决定（2.4.21），经典 KGP opt-out 需 `android.builtInKotlin=false` + `android.newDsl=false`。

### 2.2 单测（154/0）
| 模块 | 用例数 |
|---|---|
| 数据层（ApiClient/Auth/Members/UserdataMerge/UserDataRepo/Marks/Water） | 79 |
| 抽签（Validation/Engine/Workflow/Export/ConfigCodec/ConfigStore） | 69 |
| 导出命名（safeName/编号/文件名/页脚） | 6 |

- userdata v6 merge 与小程序/网页夹具**逐字节对拍**（`expected_merge_web_mp`、`expected_merge_mp_web`、`expected_v5_migrate`）。
- `safeName` 规则按规格：只替换 `[\\/:*?"<>|\s]+`，下划线保留。

### 2.3 云端真实端点冒烟（本机 curl，公开 anon key）
| 请求 | 结果 |
|---|---|
| `POST rpc/class_verify` 假身份 | `200 {"ok":false,"reason":"姓名或学号不在班级名单中"}` |
| `POST rpc/class_members` 无班级 token | `200 []` |
| `GET marks` / `GET userdata` 无班级 token | `200 []` |
- 结论：**无 token 时返回 200+空数组而非 401** → Android 端必须「本地有会话才发请求 + 空数组不覆盖缓存」，现有数据层已满足。

### 2.4 模拟器端到端（Android 17 / API 37 / x86_64 / WHPX 加速）
1. 安装 APK → 启动 → **身份核验页**（Debug 构建出现「开发预览」入口）。
2. 进入 **工作台**（底部自适应短导航：工作台/全部/我的；常用工具 4 卡 + 今日卡）。
3. **全部工具** 页（学习/班级事务/系统分组）可打开。
4. 点击抽签 → **STEP1 配置**（范围 1–70、抽 10 个、排除号、允许重复、候选来源、排序）→ **STEP2 候选确认**（70 人/号）→ **STEP3 结果**（可剔除自动重抽、重新抽签、导出）。
5. 点击「导出图片」→ 系统相册出现
   `Pictures/班级工具站/抽签结果_20261107-1541_范围1-70_抽10个_不重复_按抽取顺序.png`（116,555 B）并 Toast 提示。
6. 抽出的导出图核对：标题/副标题、**参数配置区**（两列对齐）、抽签结果数字、**斜向平铺水印 tool.furina.fun**、**生成时间**、**唯一编号 DRAW-20261107-1541-2ZQO** 全部齐全；无学号/姓名/宿舍号等隐私。

## 3. 本轮实现要点

1. **真原生、非 WebView**：全部核心页面 Compose 原生；无第三方 UI/图表/QR 库。
2. **Android 17 / M3 Expressive 落地**：品牌色 HCT 48 角色明暗色板（`#4E9082` 对白字仅 3.73:1 → primary 用 tone-40 `#24695C`）；15 baseline + 15 emphasized 中文字型（行高 +2）；official spring（spatial 0.8/380、effects 1/1600…）；edge-to-edge + 预测返回 + 自适应导航（compact 底部栏 / ≥600dp NavigationRail）；1.4.0 无 Expressive 公共组件 → 自建 8 个组件隔离在 `ui/components/expressive/`。
3. **身份门禁**：学号 10 位 + 姓名 → `rpc/class_verify` → 30 天 token → DataStore（allowBackup=false）；29 天本地有效期；401/403 统一清会话回身份页；Debug 预览会话 `debug=true` 且关闭云同步（避免假 token 写请求把预览会话清掉）。
4. **数据层**：OkHttp + PostgREST 封装（Bearer 公开 key + X-Class-Token、10s 超时、GET 重试/写不重试、no-store）；userdata v6 合并/防抖 1200ms/TTL 60s/离线 pending；marks 2min TTL/乐观更新/无 DELETE；名单 6h 缓存按 sid 隔离。
5. **抽签工具**：领域层（可注入 seed 随机、不重复/允许重复、四种排序、剔除重抽、参数校验）+ 三步 UI（600ms 防抖持久化 draw section）+ 导出 payload → 通用导出卡 v2 原生 Canvas 渲染 → MediaStore 相册 / FileProvider 分享。
6. **导出卡 v2**：`android.graphics` 两遍布局（量高→绘制）按规格 760 逻辑 px × DPR2；参数面板两列/单列判定、chips/groups/文本三种块、水印 alpha 0.03 旋转 -20° 裁剪在卡内、页脚编号；已由真机导出图与 Preview 双重验证。

| 2 | 抽签 STEP2 分组 / STEP3 结果单 | 首增量按 task 范围只做「候选预览/抽签结果」；分组引擎 + GroupsBlock 留待下一增量（导出模块已支持） |
