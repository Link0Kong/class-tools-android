## 1. 退出动画（参考 HFUT 连续性原则）

- **全局页面转场重做**（`CtPageTransitions`）：
  - 进入：右侧滑入 10% + 淡入 + 0.985→1，spring d=0.82/k=360（轻 overshoot）；
  - 被覆盖页：左移 6% + 淡出 + 缩到 0.972（层叠后退）；
  - 返回：当前页右滑 12% + 淡出 + 缩到 0.965；恢复页左推 7% + 淡入 + 0.985→1；
  - 退出统一用临界阻尼 d=1/k=420，收起干净不晃。
- **工具页返回「页面收回卡片」反向一镜到底**（新增）：
  - 顶栏返回、系统返回键都先播 280ms 全屏→卡片 bounds 的圆角收起覆盖层（先 pop 露出底层，最后 18% 淡出），无锚点/开启移除动画时退回普通 pop；
  - 进入方向仍为卡片展开成页面（340ms），进出对称。
- reduceMotion 下所有覆盖层/滑动直接切。

## 2. 通知无法联网（根因修复）

- **根因（Lead 用测试身份实测）**：CloudBase `notices?select=*` 全表响应 **13.9MB**（最新 20 条仅 ~0.55MB，21–40 条 ~3.3MB），App GET 10s 超时 → 只显示本机缓存。
- **修复**：
  - 正文改 `order=ts.desc&limit=20&offset=N` 分页：首屏最新 20 条（快速出列表），「加载更多（还有 N 条）」按 20 条/页追加；签名变化自动重载第一页；跨页仍走 NoticeDedupe；
  - 仓库层每请求 30s 超时保护 + 超时重试 1 次；失败保留已加载内容并显示「网络较慢或服务器无响应，请重试」；顶部重试强制刷新；
  - 新增 11 项分页/超时单测。
