# Round 64 报告 · v4.56.3（退出动画残留 / 学信网登录态 / 今日校园白屏 / 教务繁忙）

## 1. 退出动画结束后工具页残留
- 旧逻辑 40ms 就 pop 工具页、覆盖层 280ms 收回，两者不同步时会出现「动画结束但工具页还在」。
- 修复：反向覆盖层**全程不淡出**；等收回动画即将结束（272ms）才 pop；动画后延迟 32ms 撤层；onDone 若仍 pending 强制 pop 兜底。工具页移除与覆盖层撤除几乎同时。
- 手工录屏/抽帧验证：返回后工具页在动画窗口内消失，最终落回全部工具页（帧 ex4-029 起为根页）。

## 2. 学信网仍提示未登录
- 原因：登录跳回 my.chsi 后首帧可能是空壳，单次 400ms 提取拿不到数据；真实档案页不一定有「退出/个人中心」强信号；失败还会强制跳回登录页。
- 修复：延迟重试提取 3 次（1.2s 间隔）；判定放宽为「档案域 + 文本非营销 + 含数据信号（姓名/证件/学籍/学历/学位/报告/院校/专业）」，Cookie（session/jspsession/chsi/token 等）辅助；登录页与卡片页都显示「已登录，进入卡片页」兜底；失败不再强制跳回登录页。

## 3. 今日校园登录后空白
- 公开页证据：`/login2` 是 CAS 跳板；`/index.html` 是 2,369 B Vue SPA 外壳，登录回报停留空壳会白屏。
- 修复：登录成功显式加载门户 `index.html`；开 mixed content/缓存/第三方 Cookie；onPageFinished 500ms 注入 `innerText.length` 检测，<20 再等 800ms 复核；仍空白→清缓存重载一次（不清 Cookie）→仍空白显示「融合门户/浏览器打开/重试」错误条，不循环。

## 4. 教务提示「服务器繁忙」，微信内正常
- 可能是 App WebView UA/请求节奏触发 CAS 风控。
- 修复：教务/WebVPN WebView 改微信 UA（MicroMessenger/8.0.49 + Weixin/XWEB/MMWEBSDK）、第三方 Cookie/DOM storage/mixed content；自动填充延迟 700ms、提交前 300ms、自动仅 1 次；识别繁忙页即停止重试并提示改手动/浏览器；顶栏保留「浏览器」与「直接打开/走 WebVPN」入口。
