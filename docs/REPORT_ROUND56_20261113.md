# Round 56 报告 · v4.45.0（工具内部界面 v6 + 背景修复）

> 用户反馈：「主要对工具内部的界面不满意，还有背景也有问题」。
> 本轮针对这两点做系统性重做：**背景 v6**（去色块/色带/发灰）+ **工具内部 v6 设计语言**（统一顶栏/卡片/表单/按钮/分段/列表），并把 12 个工具页逐页迁移到同一语言；另修复迁移过程中发现的电费页崩溃与背景首版噪点带来的性能退化。版本 **v4.46.0**（versionCode 62）。

## 1. 背景 v6（`ExpressiveBackground`，全局唯一入口）

- **旧问题**：三团 alpha 0.22/0.16/0.12 的巨大径向色块，在白卡片之间露出明显绿/沙色斑；8bit 渐变轻微色带；深色偏灰。
- **新做法**：`surfaceContainerLowest→background` 极轻纵向渐变 + 顶部 primary ≤6.5% 柔光 + 右下 tertiary ≤3.5%；深色近黑中性底 + primary ≤10% / tertiary ≤5%；仅 3 个静态 rect，**无每帧 shader/模糊**。
- **性能修正**：首版加了 64×64 tiled 噪点 shader 消色带，实测模拟器每帧绘制开销上升导致导航探针偶发超时（7/10）；移除后恢复 10/10，视觉仍无可见色带。
- 所有页面（根页/工具页/身份页/设置页）自动生效。

## 2. 顶栏 v6（`CtTopBar`，全局）

- 去掉旧版整条 `surface 62%` 半透明底带；返回键为 44dp 圆形 `surfaceContainerHigh` 玻璃按钮（contentDescription 保持「返回」）；
- 标题 `headlineSmall` Bold + `bodySmall` 副标题；动作按钮由各页传入；平板 ≥840dp 收紧 padding；heading 语义保留。

## 3. 工具页设计系统（新增 `ui/components/tool/CtToolComponents.kt`）

`CtToolCard`（24dp、无硬描边、18dp padding）、`CtToolSectionHeader`、`CtToolPrimaryButton`（52dp）、`CtToolSegmented`、`CtToolChip`、`CtToolField`（填充式无描边输入）、`CtToolInfoRow`、`CtToolStat`。
详细规范见 `docs/design/TOOL_V6_DESIGN.md`。

## 5. 迁移中发现并修复的问题

1. **电费页点击即崩溃**（`IllegalStateException: Vertically scrollable component ... infinity max height`）：
   `IdleGuide` 调用处与内部都套了 `verticalScroll` → 双重滚动，空态（未关注宿舍）必崩。删除调用处多余滚动后修复；并全量走查 12 页存活。
2. **背景噪点带来的导航抖动**：移除 tiled shader，导航探针由 7/10 恢复 10/10。
3. 各页移除与 `CtTopBar` 重复的页内大标题，首屏信息密度提升。
4. 名单大字体下角色胶囊竖排换行、投票「我已投」标签重复等问题由各迁移任务一并修正。

## 7. 已知边界

- 各工具页的**复杂嵌入区**（投票配图编辑、诊断 AI flow 展开、PPT 上传进度细节）本次只统一外壳与关键控件，未重排信息架构。
- 电费/演示/名单/诊断有数据形态依赖测试身份数据，设备截图以空/错误态为主；有数据布局由预览文件（ToolV6Life/Media/ClassPreviews）覆盖，未逐张渲染 PNG。
- 背景为静态三段渐变，若个别 OLED 设备仍觉顶部光晕明显，可调 `ExpressiveBackground` 中 alpha；不提供用户级背景开关（未要求）。
