## 1. 需求与结论（用户 2026-11-10 反馈）

「希望网络良好时达到电脑本地文件的播放效果；目前 PPT 内动画全部消失，视频也依然无法播放，且各端操作都不够便捷」。

结论：分步图片模式保留（弱网/精细翻页/热点播视频），新增**「原样播放」模式**——
转换机用 PowerPoint 直接导出高保真视频（含入场/强调/路径动画、页切换、内嵌视频与声音），
Android 在网络良好时**默认播放该视频**；网络差/无视频/加载失败 → 自动回退分步浏览。
同时补便捷操作：章节跳页、倍速、续播、列表「继续」徽标、视频下载。

**已知取舍（如实说明）**：原样播放把「单击动画」合并为自动连续播放（视频是自动节奏），
需要自主控制节奏时切回分步浏览；章节时间由转换机按公式计算，允许 ±1s 误差。

## 2. `manifest.video` 契约与容错解析（§11.1）

```jsonc
"video": {
  "s": "deck.mp4", "w": 1280, "h": 720, "dur": 342.5,
  "chapters": [{"i":0,"t":0.0}, {"i":1,"t":8.7}, {"i":2,"t":15.2}],
  "q": "720p"
}
```

Android 解析（`PptParsers.parseVideo`）：

- 缺失/非对象/`s` 为空 → `video = null`（旧 manifest 不报错，走分步）；
- 章节容错：非法项忽略、越界页丢弃、同页重复取最早、按页排序、时间**单调不减**（前项夹取）；
- `w/h/dur` 非法 → 0（播放器按 manifest 比例/MediaPlayer 实测时长兜底）；
- URL 解析同 §5（相对 base；`http/https/data` 直连）→ `PptManifest.videoUrl`。

## 3. Android 实现

### 3.1 纯 Kotlin 领域层（可 JVM 单测，无 android.*）

| 文件 | 职责 |
|---|---|
| `features/ppt/PptVideoLogic.kt` | 章节查找/seek（`t+0.05`）、当前页判定、上/下一页目标、进度、`mm:ss`、倍速档位循环（1×/1.25×/1.5×/2×）、宽高比、是否看完（≥95% 或距结束 <5s） |
| `features/ppt/PptPlayMode.kt` | 模式枚举 + 默认模式选择（无 video→分步；有设备偏好→优先用户选择；否则网络良好→原样）+ 网络质量纯分类（WiFi/以太网 GOOD；Data Saver SLOW；计量移动网 <1500kbps SLOW） |
| `features/ppt/PptResume.kt` | 续播记录 `{mode,page,step,t,at}`、7 天有效、`shouldResume`（视频 >5s 且 <95%；分步不在首步/末步）、徽标判定、续播文案、JSON 编解码容错 |
| `features/ppt/PptVideoFallback.kt` | 降级状态机：错误 → 重试 1 次 → 切分步；卡顿（播放中 4s 无进度）累计 2 次 → 重试 1 次 → 切分步；进度恢复清零、暂停不算卡顿 |

### 3.2 Android 数据层

| 文件 | 职责 |
|---|---|
| `data/ppt/PptLocalStore.kt` | SharedPreferences：按 deckId 存续播 JSON（7 天外自动清理）、设备级播放模式偏好（手动切换才写入） |
| `data/ppt/PptNetworkQuality.kt` | `ConnectivityManager` → GOOD/SLOW/OFFLINE（WiFi/以太网、计量、下行带宽、Data Saver；只读，无新权限） |
| `AppContainer` | 装配 `pptLocalStore` / `pptNetworkQuality`，经 MainNavHost 注入列表页与播放器 |

### 3.3 播放器（`ui/screens/ppt/PptPlayerScreen.kt` + 新增 `PptVideoPlayer.kt`）

**模式编排**（`PptPlayerContent`）：

- 进入：读续播记录 → 判定是否自动续播（Toast「续播 12:34 / 续播 第 N 页」）；
- 默认模式：`PptModeChooser.initialMode(hasVideo, 网络, 设备偏好)`；
- 顶栏「原样 / 分步」胶囊：手动切换 → 记住设备偏好；视频失败自动回退**不写偏好**；
- 切模式保持位置：分步→原样 seek 到当前页章节 +0.05s；原样→分步跳到视频当前位置对应页。

**原样播放（`PptVideoPlayer`）**：

- 播放引擎：**MediaPlayer + SurfaceView 自建**（项目无 ExoPlayer，不新增依赖）；H.264/AAC 系统解码；
- 自动开始（用户从列表点击进入属于用户手势）；被系统拒绝/未起播 → 中央大播放按钮（不报错）；
- 自定义控制条（3s 自动隐藏；暂停时常驻）：
  - 播放/暂停、`mm:ss / mm:ss`、**上一页/下一页 = 按 chapters seek**（非 ±10s）；
  - 章节进度条（Canvas 章节刻度 + 已播放填充 + 滑块；点击/拖动 seek）；跳页后 seek 到 `chapters[i].t+0.05`，**保持播放/暂停状态**；
  - 倍速胶囊（1×→1.25×→1.5×→2× 循环，`PlaybackParams.setSpeed` API≥23，minSdk 26）；
  - 全屏 = 横竖屏切换（`SCREEN_ORIENTATION_SENSOR_LANDSCAPE` / `PORTRAIT`，退出恢复 UNSPECIFIED；播放器本身已沉浸式）；
  - 下载原样视频（DownloadManager → 系统「下载」目录，失败退浏览器）、关闭、模式胶囊；
  - 顶部标题 + 「从头」胶囊（位置 >5s 或播完时出现，契约 §11.3.4）；
- 手势/按键：点击舞台 = 显隐控制条（**视频模式不用左右 1/3 翻页**）；左右滑 = 上/下一页章节；
  Space 播放暂停、←/→ 上/下一页、F 全屏、Esc 退出、M 切模式；音量键保持系统音量（分步模式仍是 ± 翻步）；
- 失败/卡顿：`PptVideoHealth` 重试 1 次 → 自动切分步 + Toast「网络不佳，已切换分步浏览」，不白屏；
- 续播保存：每 5s / 拖动 seek / 暂停 / 退出时写本机；`DisposableEffect` 释放 MediaPlayer 并恢复屏幕方向。

**分步浏览增强（v1.1 能力保留 + §11.3.3 热点修复）**：

- 热点不依赖图片 onload（Compose 直接由当前 step 状态渲染），切页/过渡后不会漏渲染；
- 热点直径提升：视频 **64dp**、音频 48dp（原 56/40），中心对齐视频框，带「视频 m:ss」角标 + 轻微脉冲（1.0→1.07 循环）；
- 顶部进度/页码/步点/缩略图/备注/黑屏/下载原件/「从头播放」保持；续播/模式切换接入。

### 3.4 列表页

- 整卡点击 = 直接播放（播放器按网络/偏好选默认模式）；就绪卡片封面中央大「▶」；
- 7 天内有未看完进度的卡片显示「继续」小徽标（视频 >5s / 分步不在首页首步）；
- 删除/失败重试/原件下载/上传流程/10s 轮询全部保持 v1.1 行为。

## 5. 已知限制 / 风险（如实记录）

1. **OSS 默认域名的 force-download 头**：bucket 默认域名会给对象加 `x-oss-force-download` + `Content-Disposition: attachment`
   （契约 §11.4 已注明）。Android `MediaPlayer` 按内容嗅探 MP4，通常可播；但**个别机型/网络栈可能受影响**。
   兜底：失败/卡顿 → 自动回退分步（不白屏）；下载走 DownloadManager 不受影响。若后续给 OSS 绑自定义域名（无该头），直接播放路径会更稳。
2. **编码**：仅支持转换机产出的 H.264 + AAC（`+faststart`）；HEVC/外链媒体等不支持（转换机统一转码，失败则跳过该媒体/视频）。
3. **章节精度**：章节时间由转换机按动画时长公式推算，允许 ±1s 误差；`seekTo` 精度由系统 MediaPlayer 决定（通常 ±数百 ms）。
4. **倍速**：`PlaybackParams` 个别设备变速后音画轻微不同步；切倍速时若处于暂停状态，恢复播放时应用。
5. **视频体积**：720p q80，16 页约 10–40MB；弱网（Data Saver / 计量 <1500kbps / 无网）默认分步；不做整份预下载，需要离线可「下载视频」。
6. **全屏**：Android 播放器本身已沉浸式，控制条「全屏」按钮=横竖屏切换（非改变分辨率）。
7. **模式偏好**：设备级 SharedPreferences，不随账号云同步（契约要求「记住该设备偏好」）。
8. **续播**：7 天有效；视频 ≥95% 或分步在末步视为看完，不再弹「继续」。
9. **列表「重命名」仍未做**（v1.1 起 P2，未在本次范围）；列表 ⋯ 保留删除，原件下载在播放器内。
10. 未做后台播放/画中画（课堂场景不需要）。
