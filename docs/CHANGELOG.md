# 版本记录（Android 客户端）

## 1.0.1 · 相比 1.0.0（2026-11-28 正式发布，versionCode 190）

- **工作台与桌面组件**：工作台加入日期问候、实时天气和中英短句，把当前课程、下一节课和教室集中到「今日课程」。班级通知、个人待办和进行中的活动可直达详情。新增工作台、课表、通知、待办四类桌面小组件，随尺寸展示摘要或可滚动列表，可从桌面新建和完成待办。
- **课表与校园地图**：课表支持教务和个人课表，记住周／日视图，日视图左右滑动切换本周日期。工作台、提醒和桌面课表都能定位到指定课次。离线校园地图更新建筑、楼层和路线，已收录的教室可从课表直接定位。平板可并排查看课表和当天日程。
- **任务、作业与通知**：新增跨端个人任务，支持分组、星标、重复、步骤、附件、链接分享和预览导入。班级作业、通知可转成任务。AI 整理可生成待编辑草稿，确认后保存。通知支持分类、搜索、原文和附件预览，任务同步支持旧缓存恢复和并发合并。
- **提醒与实时活动**：课前、作业截止、个人任务和报名可排程提醒，也可加入系统日历。支持的设备可展示课前倒计时、报名开抢、关注的投票和文件处理进度。开课后自动撤除课前活动，报名可打开精细倒计时。
- **文件与分享**：文件传输支持个人文件互传和 PPT 转换，可取回原件及转换结果。班级课件并入同一入口，支持上传、预览和下载。扫一扫支持网页登录和抽签存证核验，课程、通知和任务分享链接可打开对应内容。
- **班级工具与宿舍数据**：新增投票、独立点名和教务服务入口。抽签与分组独立使用，分组可读取最近抽签结果。名单支持分类和搜索，宿舍电费增加同期对比、充值记录和低电提醒，水量可按宿舍共享月度读数与人数。
- **界面与稳定性**：更新品牌图标、浅色和深色主题，支持选用系统壁纸色。统一卡片、弹层和站内提示，改善大字号与窄屏阅读，平板任务页支持列表和详情并排。修复跨页界面重叠、课表边缘滑动、通知离线缓存和部分厂商推送绑定问题。
- **账号与数据**：完善账号快捷登录、权限与诊断。账号、文件、校园地图和法律文本等服务使用正式 HTTPS 地址，保留既有数据读取、导出与恢复路径。

### 功能细节与修复

- **首页内容与工具排序**：可在「我的 → 首页内容」设置天气地区、英文和短句语气。工作台通知与待办可轮换，关闭系统动画时显示静态摘要。首页快捷工具和全部工具排序跨端同步，工具与详情逐级返回。
- **课表定位与提醒**：课次详情可查看教师和完整教室，地图可区分同楼同号房间并匹配带用途后缀的教室名。上课和课间倒计时随课次状态更新，班级作业通知可查看具体内容。具备授权及配置的 OPPO 设备可使用小布建议课程卡片。
- **提醒恢复和厂商推送**：应用可在系统允许时后台补发提醒，重启或覆盖安装后重建排程，并核对账号及已发送记录。通知设置按设备显示对应厂商推送状态，可发送测试通知。定时报名可设定开抢时间，精细倒计时最后 10 秒显示毫秒。
- **更新与账号**：应用内可检查更新、查看说明，并选择立即更新、后台下载或稍后处理。下载后校验 APK 完整性。支持符合条件的 OPPO、荣耀快捷登录，切号后隔离旧会话的同步结果与本机缓存。
- **文件、抽签与分组**：同账号的上传文件重开应用或换端后可重新取件，个人文件自上传完成起保留 3 天。课件可分别下载演示文件及可用媒体。抽签可云端存证，分享结果二维码可复核，同账号的最近抽签结果可用于分组。
- **通知、班级与宿舍**：通知统一发布时间与排序，详情及附件按需获取，刷新失败时可继续阅读已有缓存。名单和点名支持搜索及自定义范围，管理员可查看访问统计。宿舍目录按云端目录加载，水量保留旧读数历史和最近抄表记录。
- **可读性与外观**：可导入自定义背景并调节玻璃效果。改善默认深色主题下的卡片、输入框及提示对比度，适配更大的系统字号、读屏和减少动画设置，修复站内提示遮挡顶栏操作的问题。
