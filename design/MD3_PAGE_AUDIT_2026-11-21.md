# 工具子页面适配核验（2026-11-21 · beta24）

> 目的：在模拟器上逐页截图核验 18 个工具入口及其可达子页面，记录修复项与仍受数据/登录限制的页面。
> 基准：MD3 官方知识库（`lwhhz/Android-MD3-Knowledge`，核验 2026-11-16）+ `design/MD3_ALIGNMENT_2026-11-21.md`。
> 设备：Android 17 模拟器 `ct-a37-tall`，1080×2400 @2.62x；Debug 包 `com.furina.classtools.debug`（beta24）。

## 1. 核验方法

- 每个工具用 `ToolActivity` 的 debug Intent 直接拉起（`TOOL_ID` + 预览会话），避免返回栈干扰；
- 截图 + `uiautomator dump` 双份取证：截图看视觉，dump 核对文字边界、是否被底栏/系统栏遮挡、触控目标尺寸；
- 浅色为默认；抽签/工具库/底栏另测深色与 200% 字体；
- 数据相关页面在未登录预览态下会进入空态/错误态，本轮按「真实会出现的状态」核验，不伪造登录数据。

## 3. 本轮统一修复（所有工具页生效）

1. **顶栏**：`CtTopBar` / `CtLightTopBar` 标题统一 Title Large 400（不再 700）；`CtLightTopBar` 首屏也保留 0.65 材质，跨页不再出现「有的页面标题浮在极光上、有的有白条」。
2. **错误态**：新增 `CtToolErrorState`（卡片 + 图标 + 用户可读文案 + 全宽重试），已接入统计、名单、点名、投票、作业、演示；统计页对 SQL/DB 原文做兜底替换。
3. **弹层/对话框**：sheet 与 dialog 容器改为**不透明**，消除实机截图里「下页文字透过弹层」的幽灵文字。
4. **重复主操作**：演示空态去掉顶栏第二个 filled 按钮；顶栏保留图标入口。
5. **筛选控件**：作业/名单去掉 chip 下 3dp 的滑动下划线（M3 filter chip 自带选中态，不再叠加 tab indicator）。
6. **可点目标**：通知顶栏返回 44→48、图标按钮 40→48；其余页面按钮/列表项按 ≥48dp 核验。
7. **状态语义**：通知统计 0 值不再用 error 红；分组 0 成员禁用主操作。
8. **文案**：课表副标题用 `joinToString(" · ")`，无周次时不再出现行首「·」。

## 4. 仍存在的产品级问题（未在本轮改）

| 项 | 说明 | 建议 |
|---|---|---|
| 抽签结果页操作过多 | 同屏有「调整参数 / 重新抽签 / 用此结果分组 / 导出抽签图 / 导出结果单 / 上一步 / 完成」7 个动作，且两个 filled 主操作 | 收进 overflow，保留「完成」或「导出结果单」一个 filled |
| 顶栏形状不统一 | 多数页是悬浮圆角条；通知/地图/教务是通栏方角条 | 统一 `CtTopBar` 的 shape 或全部改为通栏 |
| 空态与错误态样式仍有两套 | 本轮只统一了「错误态」；部分空态（名单/点名/统计无权限）仍是裸 `EmptyState` | 抽 `CtToolEmptyState` 并逐页替换 |
| 需真实身份/数据的页面 | 投票创建/详情、课表登录后视图、通知详情、作业详情、名单行、电费/水量选择弹层、PPT 上传 | 用测试账号/夹具再做一轮；本轮只核验了壳层与错误态 |
| 200% 字体 | 底栏已修；部分卡片 2 行副标题在 200% 下仍会省略 | 逐页调 `maxLines`/`heightIn` |
| 抽签号码网格 | 24sp 粗体、6 列，信息密度高 | 可降到 Title Medium 16/500 或 5 列 |

## 5. 复验命令

```cmd
# 安装 debug 包
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 直接拉起任一工具（debug 预览会话；stats 额外 --ez ...IS_ADMIN true）
adb shell am start -n com.furina.classtools.debug/com.furina.classtools.ToolActivity ^
  --es com.furina.classtools.extra.TOOL_ID draw ^
  --es com.furina.classtools.extra.SID 3260799999 ^
  --es com.furina.classtools.extra.NAME 开发预览 ^
  --ez com.furina.classtools.extra.DEBUG true

.\gradlew.bat testDebugUnitTest
```

截图与 UI dump 存于本机 `G:\ClassTools\shots\pages\`（不随仓库提交）。
