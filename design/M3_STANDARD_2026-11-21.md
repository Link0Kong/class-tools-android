> 基准：https://m3.material.io/ 组件规范；测试身份：**3260799999 / 测试账号**（真实 `class_verify`）。
> 本次不再保留「悬浮药丸 + 玻璃」混合方案，统一按 M3 surface 角色与标准 app bar 处理。

## 0.3 beta35 补充

## 0.1 beta33 补充

- **底栏改标准 M3 NavigationBar**：整宽、80dp、`surfaceContainer`，64×32 指示器 + 24dp 图标 + Label Medium；去掉悬浮圆角/边框/阴影。

## 2. 热更通道

- 配置 URL：`https://tool-furina-fun.oss-cn-hongkong.aliyuncs.com/android/config.json`（HTTPS、公开读）。
- 当前版本：`version: 1`，字段 `appearance` / `hideStatusBar` / `dynamicColor` / `timetableCompact` / `announcement`。
- 客户端启动时拉取一次，`version` 大于本机已应用版本才写入；网络失败/404/JSON 非法静默忽略。
- 只改白名单设置，不下载代码、不执行脚本；后续新增字段需在 `RemoteConfig` 与 `AppSettingsStore` 同步白名单。

## 3. 课表一屏周视图

- 手机紧凑模式：`WeekControlBar` + 周网格固定在一屏，网格高度 = 剩余高度，行高 =
  `(可用高度 - 日期头) / 12`，夹在 30–60dp。
- 固定展示 7 天（含周末），不再因周末无课隐藏列。
- 日视图仍保留滚动；平板两栏不受影响。

## 4. M3 标准替换

- Top app bar：整宽 64dp、`surface` 容器、Title Large 400、48dp 返回/动作。
- Cards：`surfaceContainerHigh` 实色 filled card，12dp 圆角。
- Dock：`surfaceContainer` + 64×32 `secondaryContainer` 指示器 + 24dp 图标 + Label Medium。
- Dialog：`surfaceContainerHigh`、28dp、Headline Small。
- Bottom sheet：`surfaceContainerLow` 不透明。
- Snackbar：inverseSurface / inverseOnSurface / inversePrimary，4dp。
- 移除所有内容卡/顶栏/底栏的玻璃材质；图标按钮改实色圆钮。
